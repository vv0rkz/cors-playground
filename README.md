# CORS Playground

Учебный репозиторий про CORS: пошаговые версии от простой ошибки до нескольких способов её решения.

Код и разбор каждой версии живут в отдельных ветках, а не в `main` — здесь нет ничего, кроме этого README.

## Начни отсюда

```
git checkout v1.0-broken
```

В README каждой ветки написано, что именно сломано в этой версии и какую ветку открыть дальше.
