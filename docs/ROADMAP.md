# CORS Livecoding — Roadmap

Каждая версия — отдельная git-ветка, ответвлённая от fixed-состояния **предыдущей** версии (кроме v2.1 — whitelist ответвляется от `v1.0-fixed`, т.к. это альтернативная реализация того же заголовка, а не следующий шаг прогрессии).

Конвенция для каждой версии:

- Первый коммит на ветке = сломанное условие упражнения → тег `vX.X-broken`.
- Финальный коммит = решение → тег `vX.X-fixed`.
- `README.md` на этой ветке описывает сценарий именно этой версии (mermaid до/после, как сейчас для v1.0) — при переходе на новую версию README.md переписывается под новый сценарий.

Чтобы повторить упражнение заново: `git checkout vX.X-broken`.

## v1.x — Диагностика и базовые CORS-ошибки

- [x] **v1.0** — нет заголовка `Access-Control-Allow-Origin` — ветка `main`, теги `v1.0-broken` / `v1.0-fixed`
- [ ] **v1.1** — заголовок есть, но origin не совпадает — ветка `v1.1` (из `v1.0-fixed`)
- [ ] **v1.2** — preflight-запрос падает (нестандартный метод/заголовок) — ветка `v1.2` (из `v1.1-fixed`)

## v2.x — Credentials и множественные origin

- [ ] **v2.0** — `credentials: 'include'` + wildcard origin несовместимы — ветка `v2.0` (из `v1.2-fixed`)
- [ ] **v2.1** — whitelist для нескольких разрешённых origin — ветка `feature/whitelist` (из `v1.0-fixed`)

## v3.x — Альтернативные способы обхода

- [ ] **v3.0** — dev-proxy вместо серверных заголовков — ветка `v3.0` (из `v2.1` или `v1.2-fixed`)
